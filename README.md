# 碳从哪里来 · Where Carbon Begins

中国省域城乡居民生活燃料直接 CO₂ 排放交互可视化。基于 2015—2022 年 CEADs 清单，以地图、趋势、燃料构成、城乡对照及 3D / 2D 图表探索生活燃料排放的分布、结构与变化。

## 数据范围

- 2015—2022 年、30 个省级地区、17 类燃料、城镇和农村两个居民生活部门。
- 排放量单位：Mt CO₂（百万吨）。人口用于计算近似人均指标，来源为国家统计局。
- 仅展示居民生活燃料燃烧的直接 CO₂ 排放，不包含购电、购热及商品服务隐含排放，不代表完整居民碳足迹。
- 2015 年人口缺失，相关人均指标保持空值；跨年变化用于描述，不用于推断因果。

## 功能与页面

| 页面 | 内容 |
| --- | --- |
| 首页 | 动态封面、自由探索与推荐入口 |
| 省域观察 | 省级地图、年份和指标切换、地区详情 |
| 年度变化 | 多省趋势、热力矩阵、面积图、桑基图、三维探索和二维精读 |
| 碳源检索 | 关键词、省份、年份、燃料及城乡筛选，图形预览和结果跳转 |
| 城乡切面 | 同省城乡燃料结构、双省对照、占比与近似人均比较 |
| 省际坐标 | 省际散点、排名和城乡燃料指纹 |
| 变化拆解 | 起终年份比较、燃料差额瀑布图、城乡变化和坡度图 |
| 数据护照 | 来源、计算边界、数值表、CSV 导出与观察链接 |

所有运行资源均位于仓库内，不需要在线 API、数据库、后端框架或构建步骤。采用 Hash 路由，切换观察状态后可通过网址恢复对应的省份、年份与视图。

## 本地运行

在克隆后的项目根目录运行：

```sh
python -m http.server 8766
```

然后打开 <http://127.0.0.1:8766/>。也可直接打开 `index.html` 离线浏览。

推荐使用最新版本 Chrome 或 Edge。三维图表需要 WebGL；不可用时提供同源二维视图与数值表。Python 仅用于启动示例本地服务器，不是网站线上运行依赖。

## 静态部署

本仓库根目录包含 `index.html`，可使用 GitHub Pages、Cloudflare Pages 或其他静态托管服务，无需购买独立云服务器。部署时保留 JavaScript、CSS、`data/`、`vendor/` 与第三方声明；不要上传原始工作簿、凭据或本地协作资料。

本次提交仅上传项目代码，不启用网站发布或配置自定义域名。计划域名 `zhaiyifei.xin` 尚需另外配置托管、DNS 和 HTTPS；域名实名认证不等于 ICP 备案。使用中国大陆托管资源通常需先满足备案等接入要求，其他区域的访问效果也应在实际部署后测试。

## 验证

安装 Node.js 后可运行无需第三方依赖的数据与静态检查：

```sh
node tests/verify-data.cjs
```

浏览器测试脚本位于 `tests/`，另需 Playwright 与本机 Chrome。可用 `TEST_URL` 指定预览地址、`CHROME_PATH` 指定 Chrome 路径。生成的 `tests/artifacts/` 截图不提交到仓库。上述测试工具不是网站运行依赖。

## 主要文件

- `index.html`：页面结构和导航。

- `routes.js`、`reading.js`：页面路由、页内导航和导览。
